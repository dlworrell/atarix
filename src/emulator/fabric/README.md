# ATARIX Fabric Emulator

This directory will contain the emulator-side model of the Fabric Northbridge.

Initial scope:

- fabric identity registers
- mailbox endpoint model
- discovery fixture support
- service-directory fixture support
- Boot Information Block fixture support
- deterministic trace output

The first emulator model should be architecturally accurate, not cycle accurate.
