# ATARIX Mailbox Emulator

This directory will contain emulator support for CPU-card to Fabric Northbridge mailbox transport.

Initial scope:

- mailbox packet encode/decode helpers
- transaction ID tracking
- synthetic request/reply traffic
- DMA descriptor message fixtures
- deterministic logging for firmware tests
