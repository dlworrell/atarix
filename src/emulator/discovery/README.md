# ATARIX Discovery Emulator

This directory will contain emulator support for Discovery ROMs, Identity EEPROM fixtures, capability records, and service enumeration.

Initial scope:

- load synthetic Identity EEPROM records
- load synthetic Discovery ROM records
- validate checksums
- expose discovered devices to the fabric emulator
- build Service Directory fixtures
