# Architecture Decision Records

ADR documents capture significant architectural decisions.

## Required Sections

- Title
- Status
- Date
- Context
- Decision
- Evidence
- Alternatives Considered
- Consequences
- Future Revisions

## Engineering Rule

Major architectural decisions should be supported by evidence whenever practical.

Measure first. Decide second. Document always.

ADR-0000 is reserved for the Catylist Code of Conduct (ring 0): [ADR-0000](ADR-0000-catylist-code-of-conduct.md).
